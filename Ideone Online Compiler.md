## 🎯 Overview

**Ideone** is a free, browser-based online compiler and IDE that lets you write, run, and share code in over **60 programming languages** — no installation, no signup required. It's a favorite among students, teachers, competitive programmers, and anyone who needs to quickly test a snippet.

Behind the scenes, Ideone runs your code in a sandboxed virtual environment on a secure server, capturing standard output, errors, and execution time.

## ⚠️ Privacy Notice

> **🛑 Read Before Using**
>
> By default, code and output on Ideone are **public**. Anyone with the link can see them.
>
> - ✅ **Safe:** Practice problems, tutorials, non-sensitive code
> - ⚠️ **Risky:** Proprietary algorithms, API keys, personal data
> - ❌ **Never paste:** Passwords, tokens, credentials, private datasets
>
> Use the **private** option when in doubt.

## 🚀 Advanced Usage

### 🔌 API Access

Ideone offers a **Sphere Engine API** for programmatic runs:

```bash
curl -X POST https://api.ideone.com/submit \
  -d "source=print('Hello')" \
  -d "language=116" \
  -d "api_key=YOUR_KEY"
```

## 💬 FAQ

**Is Ideone free?**
Yes — free for public use, with API for enterprise.

**Do I need an account?**
No — but signing up lets you manage pastes.

**Are my pastes private by default?**
No — public unless you enable private mode.

**Which languages are supported?**
Over 60, including Python, Java, C++, Rust, Go, Kotlin.

**Can I use it for exams?**
That depends on your institution's rules.

**Does it support file input?**
Not directly — use stdin.

**Can I save code?**
Yes — save as a paste with URL.

**Is there an API?**
Yes — the Sphere Engine API.

**Does it support multi-file projects?**
No — single-file only.

**Can I embed output in a blog?**
Yes — via embed code.
